### 2026-07-17 — Capture is the Last Best Chance

The Capture workflow is the one moment when both the physical object and the user's memory are
available at the same time. AI should contribute everything it can infer at that moment — product
name, brand, model, category, quantity, tags, the original capture photo, a confidence score, and
a description when appropriate. The user should only ever be asked for what AI genuinely cannot
know: current zone, container/shelf, project, collection, notes, and any other metadata specific
to the owner's own organization scheme — asked immediately after AI review, while the item is
still in hand, and always skippable.

Goal: an inventory item should rarely need editing after capture. Not part of any current
milestone — pure future product direction, captured so it isn't lost. Relates to
[lessons-learned.md](lessons-learned.md)'s notes on AI-info discard between extraction and the
saved item, and to the deferred photo-storage / confidence-preservation backlog items there.
