# Knowledge Folder

**Purpose:** capture ideas without derailing the task in progress.

When an idea, improvement, workflow thought, architectural observation, UX insight, or future
enhancement comes up mid-work, it gets a short note here — not a build. The conversation returns
to the original task immediately after. Nothing here gets built until it's explicitly picked up
later.

Each file below is a running log for one category. Append a dated entry; don't create a new file
per idea. Keep entries to 1–2 minutes of writing — a sentence or three of context is enough.

Entry format:

```md
### YYYY-MM-DD — Short title
Brief capture of the idea and why it came up. Link related docs if relevant.
```

## Categories

| File | For |
|---|---|
| [future-features.md](future-features.md) | Product features not on the current roadmap |
| [workflow-improvements.md](workflow-improvements.md) | Dev workflow, tooling, process ideas |
| [ai-prompt-ideas.md](ai-prompt-ideas.md) | Prompt/model changes for `/api/extract` and future AI layers |
| [product-direction.md](product-direction.md) | Bigger-picture product/positioning thoughts |
| [business-opportunities.md](business-opportunities.md) | Monetization, market, non-engineering ideas |
| [architecture-observations.md](architecture-observations.md) | Things noticed about the current architecture, not yet acted on |
| [lessons-learned.md](lessons-learned.md) | Debugging discoveries, gotchas, "next time do X" notes |
| [ux-improvements.md](ux-improvements.md) | Interaction/UI ideas that aren't the current task |

If an idea doesn't fit any category, add it to the closest one rather than inventing a new file —
ask first if none fit well.
